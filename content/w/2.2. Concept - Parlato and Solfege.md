# Concept - Parlato and Solfege
<br/>

## Parlato

Parlato is the speaking of note names in time, briefly ignoring the pitch but retaining the rhythm.

Parlato is a great way for us to make sure we're understanding the progression of notes as we move through a piece. Parlato can use regular note names or solfege note names!
<br/>

## Solfege

Solfege is the *singing* of note names in time, retaining both the pitch and rhythm.

Solfege is a fantastic method for hearing the notes we're singing. There are two types of solfege, *fixed Do*, and *movable Do*. *Fixed Do* means the notes are sung with the same names all the time, no matter what. In my studio, we sing *fixed Do* using note names.

For my students, I give them the option to use German/Dutch note names (C D E F G, etc.) or French note names (Do Re Mi Fa So, etc.). For myself personally, I like to use German/Dutch note names when singing *fixed Do*, and French note names when singing *movable Do*.

## Movable Do
<br/>

Here is an example of *movable Do* using the same piece: 

![[Solfege-3.svg]]
<br/>

The thing that makes it "movable" however, is that we call a different note "Do" depending on what key we're in. In the key of C, C is Do. In the key of G, G is Do. This pattern goes on into all keys. The other notes are given names relative to Do changing as well.
<br/>

Here is an example of the same piece in the key of G, solfege moved around:

![[Solfege-5.svg]]

| ---- | ---- | ----- |

| Re   | Ra   | Ri    |
| Mi   | Me   | -     |
| Fa   | -    | Fi    |
| So   | Se   | So    |
| La   | Le   | Li    |
| Ti   | Te   | -     |
