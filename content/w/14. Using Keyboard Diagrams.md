The next section features diagrams of the piano with various scales and chords labelled. In a new scale or chord, we give every note a number. If a note is "1" it means that it's our home base, but it doesn't mean we always have to start on 1. We can play scales from 2 to 2, for example - or we can play chords in *inversion*.

This is a great way to calculate sequences too! If we know that a sequence goes:

1 2 3 4, 2 3 4 5, 3 4 5 6, Etc. 

Then we can play the pattern in any scale by changing the note we refer to as "1".


#### Recommended Workflow for diagrams:

1. Play the keys in order starting at 1, any octave.

2. Play the keys in all other orders!

3. Play the keys skipping numbers or doing other patterns and sequences.



> TIP
>
> Sing at all times on numbers or solfege! Ask your teacher for help converting numbers into solfege.

> NOTE
>
> Remember that the piano uses *modular math*, the same type of math that clocks use. The note names and numbers repeat on a cycle. Similar to how if we add 2 hours to 23:00 then we get 01:00, if we move up two steps from 7 we get 2.
